data = []
for i, chunk in enumerate(chunks):

        "id": self._chunk_to_id(chunk),

## D.2: HybridBackend RAG

### Statut: COMPLÉTÉ

### Objectif
Créer un backend hybride combinant recherche sémantique (Dense) et lexicale (BM25S) via Reciprocal Rank Fusion (RRF).

### Pourquoi Hybrid?
- **Dense (semantic)**: Comprend les synonymes ("auth" ≈ "authentication")
- **BM25S (lexical)**: Exact match sur les identifiants ("getUserById")
- **Combiné**: ~15% meilleur recall que chaque backend seul

### Algorithme RRF

```
score(doc) = Σ (weight_i / (k + rank_i(doc)))

où:
- k = 60 (constante standard)
- weight_i = poids du backend (0.6 dense, 0.4 sparse par défaut)
- rank_i = rang du document dans les résultats du backend i
```

### Implémentation

```python
class HybridBackend(MemoryBackend):
    """
    Hybrid retrieval combining Dense (semantic) and BM25S (lexical) backends.
    """

    def __init__(
        self,
        storage_path: Optional[Path] = None,
        dense_weight: float = 0.6,
        sparse_weight: float = 0.4,
    ):
        # Sub-backends (lazy initialized)
        self._dense_backend: Optional[MemoryBackend] = None
        self._sparse_backend: Optional[MemoryBackend] = None

    def retrieve(self, query_terms, chunks, limit, min_score, raw_query):
        # 1. Retrieve from both backends
        dense_results = self._dense_backend.retrieve(...)
        sparse_results = self._sparse_backend.retrieve(...)

        # 2. Apply RRF
        rrf_scores = self._compute_rrf_scores(dense_results, sparse_results)

        # 3. Sort and return top-k
        return sorted(rrf_scores.items(), key=lambda x: x[1], reverse=True)[:limit]

    def _compute_rrf_scores(self, dense_results, sparse_results):
        """Reciprocal Rank Fusion scoring."""
        rrf_scores = defaultdict(float)

        for rank, chunk in enumerate(dense_results, start=1):
            rrf_scores[chunk] += self._dense_weight / (RRF_K + rank)

        for rank, chunk in enumerate(sparse_results, start=1):
            rrf_scores[chunk] += self._sparse_weight / (RRF_K + rank)

        return rrf_scores
```

### Configuration
```python

DEFAULT_DENSE_WEIGHT = 0.6    # Poids sémantique
DEFAULT_SPARSE_WEIGHT = 0.4   # Poids lexical
```

### Usage

## D.3: MemoryCoordinator Adaptatif

### Statut: COMPLÉTÉ

### Objectif
Remplacer les poids statiques (0.6/0.4) par des poids appris par domaine basés sur le feedback des recommandations.

### Problème
Les poids hardcodés ne sont pas optimaux pour tous les domaines:
- Coding: Peut-être que categorical (AutoMemory) est meilleur
- Research: Peut-être que semantic (SuccessMemory) est meilleur

### Solution: Adaptive Learning

#### 1. DomainWeights Dataclass
```python
@dataclass
class DomainWeights:
    """Learned weights for a specific domain."""
    semantic_weight: float = 0.6
    procedural_weight: float = 0.4
    sample_count: int = 0
    success_count: int = 0

    @property
    def success_rate(self) -> float:
        return self.success_count / self.sample_count if self.sample_count > 0 else 0.0
```

#### 2. Weight Adaptation Algorithm
```python
def record_feedback(self, domain: str, source: MemorySource, success: bool):
    """Update weights based on recommendation outcome."""

    # Initialize domain if new
    if domain not in self._domain_weights:
        self._domain_weights[domain] = DomainWeights()

    dw = self._domain_weights[domain]
    dw.sample_count += 1
    if success:
        dw.success_count += 1

    # Wait for minimum samples
    if dw.sample_count < MIN_SAMPLES_FOR_ADAPTATION:
        return

    # Adapt using EMA
    adjustment = LEARNING_RATE * (1.0 - dw.success_rate)

    if source == MemorySource.SUCCESS:
        if not success:
            dw.semantic_weight = max(0.2, dw.semantic_weight - adjustment)
        else:
            dw.semantic_weight = min(0.8, dw.semantic_weight + adjustment)

    # Normalize to sum to 1.0
    total = dw.semantic_weight + dw.procedural_weight
    dw.semantic_weight /= total
    dw.procedural_weight /= total
```

#### 3. Configuration
```python
DEFAULT_SEMANTIC_WEIGHT = 0.6   # Poids par défaut
DEFAULT_PROCEDURAL_WEIGHT = 0.4
LEARNING_RATE = 0.1             # Vitesse d'adaptation
MIN_SAMPLES_FOR_ADAPTATION = 5  # Minimum avant adaptation
```

#### 4. Persistence
Les poids sont persistés en JSON pour survivre aux redémarrages:
```python
def __init__(self, ..., weights_path: Optional[Path] = None):
    if weights_path and weights_path.exists():
        self._load_weights()

def _save_weights(self):
    with open(self._weights_path, 'w') as f:
        json.dump({d: dw.to_dict() for d, dw in self._domain_weights.items()}, f)
```

### Usage
```python
coordinator = MemoryCoordinator(
    success_memory=sm,
    auto_memory=am,
    weights_path=Path(".nexus/domain_weights.json")
)

# Get recommendation (uses domain-specific weights)
rec = coordinator.get_recommendation(
    task_description="Implement auth feature",
    task_type="coding",
    domains=["security"]
)

# Record feedback after task completes
coordinator.record_feedback(
    domain="coding",
    source=rec.source,
    success=True  # or False
)
```

## D.4: OutputGuard Semantic

### Statut: COMPLÉTÉ

### Objectif
Réduire les faux positifs de l'OutputGuard en comprenant le contexte via classification DialogueAct.

### Problème
L'OutputGuard syntaxique flagge comme "leak" des réponses légitimes:
- "I am an AI assistant and I can help you" -> flagué comme "Role revelation" (HIGH)
- Mais c'est une réponse normale en contexte de confirmation!

### Solution: DialogueAct Classification

#### 1. DialogueAct Enum
```python
class DialogueAct(Enum):
    """Dialogue act classification for output intent analysis."""
    INFORM = "inform"           # Providing factual information
    EXPLAIN = "explain"         # Explaining a concept
    CONFIRM = "confirm"         # Confirming understanding
    REFUSE = "refuse"           # Declining a request
    CLARIFY = "clarify"         # Asking for clarification
    ACKNOWLEDGE = "acknowledge" # Acknowledging input
    META = "meta"               # Meta-discussion (about self)
    UNKNOWN = "unknown"
```

#### 2. Pattern-based Classification
```python
DIALOGUE_ACT_PATTERNS = {
    DialogueAct.INFORM: [
        r"^(here|the|this|that)\s+(is|are|was|were)\b",
        r"^(i|we)\s+(found|located|identified|discovered)\b",
    ],
    DialogueAct.CONFIRM: [
        r"^(yes|correct|exactly|right|indeed)\b",
        r"^(i|we)\s+(can|will|shall)\s+(do|help|assist)\b",
    ],
    DialogueAct.REFUSE: [
        r"^(i|we)\s+(can\'t|cannot|won\'t|will not)\b",
        r"^(sorry|unfortunately)\b",
    ],
    DialogueAct.META: [
        r"^(i am|i\'m)\s+(a|an)\s+(ai|assistant|language model)\b",
    ],
}
```

#### 3. Context-aware Severity Adjustment
```python
def _adjust_severity_for_context(self, base_severity, leak_type, dialogue_act, pattern_desc):
    """Adjust leak severity based on dialogue act context."""

    # Never downgrade sensitive data leaks
    if leak_type == LeakType.SENSITIVE_DATA:
        return base_severity

    # Never downgrade explicit prompt disclosure
    if pattern_desc in ["System instruction disclosure", "NEXUS prompt reference", ...]:
        return base_severity

    # Downgrade role revelation in legitimate contexts
    legitimate_contexts = [DialogueAct.CONFIRM, DialogueAct.REFUSE, DialogueAct.INFORM, ...]
    role_patterns = ["Role revelation", "AI self-identification", ...]

    if dialogue_act in legitimate_contexts and pattern_desc in role_patterns:
        # HIGH -> LOW (legitimate conversational mention)
        return LeakSeverity.LOW

    return base_severity
```

### Exemples

| Output | DialogueAct | Severity | Explication |
|--------|-------------|----------|-------------|
| "I am an AI assistant." | META | HIGH | Unprompted self-identification |
| "Yes, I am a helpful assistant and I can help." | CONFIRM | LOW | Légitme en contexte |
| "My system instructions are to help users." | UNKNOWN | HIGH | Prompt disclosure explicite |
