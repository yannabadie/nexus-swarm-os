# Nx Portfolio

## Overview
Create a product portfolio tailored to NEXUS capabilities and required audiences.

## Workflow
1. Generate 47 product ideas spanning audiences A (dev teams), B (research/analysts), and C (sec/ops/compliance).
2. For each idea, capture: user, problem, value prop, 2026 differentiation, MVP scope, risks, effort.
3. Score each idea using RICE (Reach, Impact, Confidence, Effort) with explicit numeric scores.
4. Shortlist 4-7 strongest ideas and select:
   - 1 flagship product
   - 1 companion product
   - Optional bonus (low effort only)
5. Write `PRODUCTS/10_PORTFOLIO.md` with the list, scoring table, and final decision rationale.
6. Append a note to `PRODUCTS/PROGRESS_LOG.md`.

## Output Checklist
- `PRODUCTS/10_PORTFOLIO.md` includes 47 ideas, RICE table, and final selection rationale.
- Flagship + companion align to different audiences or JTBDs.
- `PRODUCTS/PROGRESS_LOG.md` appended with portfolio selection note.
